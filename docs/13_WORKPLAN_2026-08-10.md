# 감사 잔여 작업계획 (Master Work Plan) 2026-08-10

> docs/10(UX)·docs/11(코드) 감사의 **미착수·잔여** 전량을 트리아지해 우선순위·효율·의존성·배치로
> 구성한 실행계획. 처리 완료분은 [docs/12](12_REMEDIATION_2026-08-10.md).
> 방식: 3개 병렬 트리아지(코드 P2 70 / 코드 P3 120 / UX P2·P3 136) + 표본 대조 검증.
> 원칙: **보안·행-인가 → 금전·데이터 정합 → 정직(에러 삼킴) → AA 접근성(법적) → 유지보수 →
> 신뢰성·성능 → 카피·크래프트**. 마이그레이션은 프로드 중복점검·스테이징 선행, 카피/요율은 편집이
> 아니라 **의사결정**(office-hours/CEO 리뷰)으로 처리.

## 3. 배치 실행 계획

### Batch A — 보안·행-인가 (Critical, 코드+RLS 1마이그레이션)
- 코드 P1-1 + P2-7 (page-레벨 `verifyAdmin()`), P3-18·P3-92 (행-인가·자격증명), UX P2-20·P3-36·P3-44(metadata authz), P2-68(RLS sender_id 바인딩·mig), P2-70(slug 불변·mig), P2-15(publish후 재검수).
- RLS/트리거는 **한 마이그레이션**으로 묶어 스테이징 검증.

### Batch B — 금전·데이터 정합 (High)
- **덧셈 마이그레이션 1개**: 부분/유니크 인덱스 묶음(P1-3 `matching(request_id,expert_id)`, P1-10 `review(deal_id,author_type)`, P3-63 `service_order` 멱등, 코드 T1 클러스터 dispute/invitation/candidate) + 코드에서 `23505`→기존 한국어 409 매핑. **프로드 중복점검 쿼리 선행**(docs/12 §3).
- 코드 P1-13 잔여(§0 P2-50), P3-84·P3-98 (가짜 성공·보상 고착), CAS 잔여(P2-8/11/58).
- **설계 착수**: P1-9(refund 예약), P1-17(release RPC).

### Batch C — 정직 스윕 (코드전용·기계적, Med)
- 코드 T3(에러 삼킴 16) + P3 테마 A(raw error 7)·B(unguarded json 5)·C(경계값 10)·D(길이캡 6)·M(DB실패→not-found 10).
- UX T2(에러→빈상태 8)·T15(원시/혼용 에러카피 5).
- 패턴: `error` 구조분해·검사, PGRST116 구분, 서버 로그+일반 한국어 메시지, 실패결과 캐시 금지.

### Batch D — AA 접근성 (법적 구속, EAA 2025-06-28~)
- **D1 토큰 대비**(UX T9: P2-47/48/P3-85) — `--success/--warning/--text-subtle` 토큰 1회 수정으로 전 배지·토스트 동시 해결. **최고 ROI.**
- D2 미라벨 입력(T6 5건) + 에러 aria-live(T1/T23 일부).
- D3 토글/탭/라디오 시맨틱(T7 9·T8 2) — 공용 Tabs/Toggle/StarRating 프리미티브.
- D4 조작성(T10: 포커스트랩·Esc·회전자 pause·타깃 24px).

### Batch E — 유지보수·드리프트 방지 (공용 모듈 먼저)
- **B1 우선**: 공용 label/color 모듈 + **pinning 테스트**(코드 T6, UX T17 — 배지 추가작업 전에).

### Batch F — 신뢰성·성능
- SSR 프록시 쿠키 동기화(P2-18/52 + expert), cancelPayment 계약화(P2-63), 아웃바운드 타임아웃(P3-X).

### Batch G — 카피·크래프트 (마지막, 다수는 **의사결정**)

## 4. 레버리지 & 의존성 (효율)

- **한 번 고치면 다수 해결**: ① 토큰 대비(D1)=전 배지, ② 공용 label/color 모듈(E)=드리프트 다수, ③ 유니크 마이그레이션 1개(B)=T1 전체, ④ vitest 확장=금전경로 고정.
- **순서 의존**: E의 공용 모듈 → 이후 배지/라벨 편집 전에. B의 마이그레이션 → 동시성 회귀 테스트 전에. D1·E-SearchBox·B1이 "fix-once" 3종.
- **병렬 가능**: C·D·F는 상호 독립.
- **게이팅**: 모든 마이그레이션은 프로드 중복점검→스테이징. 카피/요율은 코드가 아니라 승인 필요.
